# 📊 Sample Superstore Analysis – Power BI

An interactive **Power BI dashboard** built using the Sample Superstore dataset to analyze sales, profit, quantity, orders, products, and business performance.

## 📌 Dashboard Overview

### 1. Sample Superstore
Key KPIs and performance metrics:
- Total Sales
- Total Quantity
- Total Orders
- Office Supplies Sales
- Sales Rank by Segment

### 2. Cohort Analysis
Detailed analysis of:
- Sales & Profit
- City Coverage
- Product Performance
- Total Quantity
- Postal Code
- Sales by Category

## 🛠️ Tools Used

- Power BI
- DAX
- Power Query
- Excel / Sample Superstore Dataset

## 🎯 Project Objective

To transform raw sales data into an **interactive and visually engaging Power BI report** that provides meaningful insights into sales, products, categories, and business performance.
